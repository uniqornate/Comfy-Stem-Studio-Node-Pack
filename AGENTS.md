2. Read the CONTROL BLOCK in `docs/HANDOFF.md`.
3. Read `docs/HANDOFF_PROTOCOL.md`.
4. Reconcile project plans with the control block before editing.

6. Before finishing, validate, update the control block, and sign the log.

`AGENTS.md` is canonical. Provider adapter files only point here.

## Project-specific instructions

- This repository is the ComfyUI custom node pack. The Electron desktop app lives in its own repository (https://github.com/uniqornate/Comfy-Stem-Studio). Do not copy desktop-only code here. Pure modules shared by both are in `src/shared/`, `src/graphs.mjs` and `src/engine-status.mjs`; keep them free of Node and Electron imports.
- The user owns live testing. Do not open a browser on the app, play media, run real ComfyUI jobs, or perform live connection/model tests unless the user explicitly requests that specific testing. Static checks and builds may be run.
- Never generate images unless explicitly requested. Do not use em dashes in user-facing output unless requested.
- Keep implemented, planned, and user-verified features distinct. Never show simulated separation output as real inference.
- The built web app is committed in `comfy_nodes/StemStudio/app`. Rebuild it with `npm run build` after any change under `src/`, and keep `version` in `package.json` and `pyproject.toml` equal.
- `setup/extra-models.json` is generated by `npm run make:models` from `src/shared/*.mjs` and `setup/mmaudio-manifest.json`; never edit it by hand.
